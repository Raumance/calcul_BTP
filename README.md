# calcul_BTP
Calculs BTP : une application multiplateforme de quantitatifs et devis pour le bâtiment.  Architecture :  Client unique Flutter (Android, iOS, Windows, Linux, macOS) API Django REST + PostgreSQL Sync temps réel via WebSockets (Django Channels) Calculs locaux hors-ligne (&lt; 200 ms), sync multi-appareils Conteneurisation Docker
